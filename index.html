token 只发送到本机 127.0.0.1 服务，不写入浏览器、localStorage 或代码；已配置后输入框可留空，直接同步。



      

        页面显示“未连接本地服务”？
        
GitHub Pages 是静态托管，不能直连 X API。请在项目目录启动本地服务：

        
python3 server/app.py --open

        
然后打开 http://127.0.0.1:8787，再输入 token。token 只存在本机服务内存，重启即失效。

        
GitHub Actions 的每日自动更新仍然走 Secrets，不需要在页面输入 token。
